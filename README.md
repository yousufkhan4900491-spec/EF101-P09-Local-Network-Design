# EF101-P09-Local-Network-Design
EF101-P09 | Local Network Design and Performance Investigation

Project Overview:
This project focuses on designing, configuring, and investigating a small Local Area Network (LAN) using Cisco Packet Tracer. It aims to develop an understanding of network architecture, device communication, IP addressing, and network performance through simulation and practical testing.

Project Objectives:
- Design a network topology using a router, switch, access point, and end devices.
- Identify wired and wireless network connections.
- Configure and record IP addresses, subnet masks, default gateways, and MAC addresses.
- Understand DHCP and static IP addressing.
- Test network connectivity using the PING command.
- Perform DNS name resolution.
- Measure local file transfer time and throughput.
- Perform Internet speed testing where available.
- Compare wired and wireless network performance.
- Understand the functions of routers, switches, access points, and Network Interface Cards (NICs).

Network Components:
- Router
- Network Switch
- Wireless Access Point
- Desktop Computers
- Laptop
- Ethernet Cables
- Wi-Fi Connection

Tools and Technologies:
- Cisco Packet Tracer
- IPv4 Addressing
- DHCP Configuration
- Static IP Addressing
- DNS
- PING Command
- Network Performance Testing

Network Performance Analysis:      
                                                                                                                            The project investigates the following networking concepts:
- Latency vs. Bandwidth
- Wi-Fi performance based on distance and interference
- DHCP vs. Static IP Addressing
- Local Network Traffic vs. Internet Traffic
- Data Packet Transmission
- Communication when the Default Gateway is unavailable

Practical Testing:

The required practical investigations include:

- IP configuration verification
- Local connectivity and latency testing
- DNS resolution testing
- File transfer and throughput measurement
- Internet bandwidth testing where available
- Wired vs. wireless performance comparison
- At least one real network measurement using actual hardware
